# Fonts (for offline play)

Once the fonts are chosen in the style test, download them so the game works without internet:

1. Open fonts.google.com and search for the font name (e.g. "Limelight").
2. Click **Get font**, then **Download all**.
3. Unzip, and copy the `.ttf` files (from the `static` folder if there is one) into this folder.
4. Tell Claude; the game will then load fonts from here instead of the internet.

All candidate fonts use the SIL Open Font License, which allows this.
